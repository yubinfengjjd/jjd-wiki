# area

## 回答什么问题

回答“沿一个有序序列，总量如何变化、总量内部各类别的占比如何随之改变”，以及某个类别的份额是否在序列中系统性扩张或收缩。论证目标是展示组成的连续演变和相对份额，而不是给出某一时点各类别的精确数值。

## 什么时候选它

当 x 轴本身有顺序（时间、剂量、有序分类、样本序列）、各类别可相加，且作者关心“总量+组成”而非单条曲线的精确读数时选它；各组总量差异大、只需比较内部构成时用 100% 堆叠面积。数据上，序列位置要足够多（经验上至少 5–6 个），类别数约 3–8 个，每个位置都有可比的计数或比例；只有 2–3 个位置时柱状更诚实。本库的 area 模板对应另一种数据形状：每个观测一行，带 group/stat 两个分类标签，模板按 group×stat 计数并转为百分比；group 有序时可直接用；模板默认 100% 堆叠、按 percent 画，`style.stat_type` 可覆盖为 count，组顺序由 `style.group_levels` 显式固定，模板不推断发育序列。

## 什么时候不要用

x 轴无序（如细胞类型、器官、模型名）时不要用面积，相邻位置的连线会凭空制造顺序和中间状态；只有两三个 x 位置，或需要精确比较每个类别的值时，改用柱状或点图。类别不互斥、可重复计数，或总量不可相加时，堆叠面积会把重复量画成 100%，产生错误整体。序列有缺失位置、各位置样本量差异很大却画原始计数时，面积高度反映的是抽样量或插值而非生物学变化；这种描述性图也不能代替组间统计检验。

## 与相近图型怎么区分

与 `stacked-bar-flow` 相比：后者用离散柱加相邻组流带展示按组归一化的比例，适合少量离散条件、需要看清每组柱高；area 用跨全部 x 的连续填充带，适合 x 有序且位置较多的组成剖面。与 `trend` 相比：trend 是堆叠柱加面积连接、按 count 画，强调有序组间的计数变化；本库 area 默认 100% 堆叠、按 percent 画（`stat_type` 可覆盖），强调组内份额。与 `bar` 相比：本库 bar 只有 SHAP 汇总模板；通用柱形对无序类别和少量 x 位置的精确读数更好；与 `pie`/`ring`/`rose` 相比：它们也能画多个离散分组，但没有有序 x 轴，不能表达沿序列的连续构成变化；area 多出的是“有序轴”这一维。

## 常见误用

堆叠面积只有最下层有 0 基线、最上层有 100% 基线，中间带的厚度可读而上下位置不可读，序列交叉或排序变化容易被误读成某类“先降后升”，关键值应直接标注或另配柱/表。用各 x 位置的均值画面积而不给 CI/误差带会掩盖样本间变异，原始计数还会被各位置样本量差异主导；离散条件之间的直线插值暗示了未测量的中间值，面积下的积分不能当作累积量或暴露量。非 100% 面积图把 y 轴截到 0 以上会放大差异；类别过多（约 >8）或只靠图例配色在色盲/灰度下难以分辨；本库模板固定 8×6 时首末百分比标签会被 panel 边界裁切，图示只说明组成，不能据此宣称组间差异显著。
