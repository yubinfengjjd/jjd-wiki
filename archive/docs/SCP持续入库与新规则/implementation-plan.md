## 工作顺序与审查点

1. **全量盘点**：对固定源码NAMESPACE/文档/示例逐项归类，交叉查正式方法、实现、technical/workflow、模板、接口和旧工作SOURCE_TO_OUTPUT。产出统一coverage.csv/json：原始入口/分支、目的和单位、现有规范id、对应资产、算法/独立性/回放/作者状态、缺口、准确来源、下一动作。辅助函数标明排除理由，不按每函数造方法页。精确列出旧S1–S3尚未完成的分支和S4+剩余项。
2. **方法侧优先**：同一目的补已有家族/实现；新的分析目的先提出有证据的归属方案。按输入语义/样本单位/算法假设去重，补最小运行闭包、必需/可选包和显式参数，保持正常科学行为。先处理现场已发现的scp-detest options恢复缺陷：只修复副作用边界/真实诊断，不改原始归档或统计；成功与异常、新增option/原有option、search恢复均实际核查。原版/修订版输出比较、异目录复制和新进程调用缺一不可；新证据覆盖实际执行代码，旧收据保留，未运行不能重绑哈希标passed。
3. **图样侧续做准备**：检查CellDimPlot/FeatureDimPlot、FeatureStat、Enrichment/GSEA、Dynamic、Lineage/PAGA/Projection/Velocity/Graph、3D/HTML和旧热图/CellStat未覆盖分支。先读真实来源、与既有图样按结构/编码去重，形成单panel样式卡与来源/bbox/数据/代码证据。新代表样式的关键选择明确后再正式提炼/收录；不做整组，不把静态替代当交互/3D已支持。只做本机真实材料支持的分支；缺包保留not_run。
4. **逐批提炼/验证**：在隔离副本做原版/提炼版比较、最小闭包复制、新进程、换合法数据/规模、输入不变及实际图像核查。绘图保留原生主题、色板、几何与布局；不能用相似重画冒充原生。新增字段可选必须有代码依据，不隐式聚合、填补、换算或重做统计。
5. **编译与关联**：按最新八步收录更新必要方法正文、接口含义、图型判断、figure_relations唯一主记录；研究领域tags与用途purposes同源，具体软件词放keywords。来源panel留画廊，只在Wiki留指针；关系兼容与实际运行验证分开。新来源/模板/方法保留需要作者确认的真实状态。
6. **独立验收/发布**：Codex检查实际差分、源/作者保护、原版对照、命令和输出、闭包/收据哈希、实际CLI/API/浏览器。失败由已结束的同一Devin会话resume修复；不重复启动。通过后备份整合正式Wiki/画廊增量，save、受影响check-entry、lint/pending，必要时用tools/deploy.py同步五处技能，准确重启服务。不伪造作者确认、不扩大验证范围。
