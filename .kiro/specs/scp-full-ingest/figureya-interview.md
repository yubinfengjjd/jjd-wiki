# FigureYa 入库采访（在选中项 [ ] 里填 x，保存后告诉我"选好了"）

背景（已核实，来源 https://github.com/ying-ge/FigureYa README）：
- 数百个独立模块，每个目录 = `*.Rmd`（分析+绘图代码）+ `install_dependencies.R`（自动安装依赖）+ `easy_input_*`（示例输入，多为 CSV）+ `example.png`（目标样式）+ 输出 PDF/`output_*`。
- 输入是**表格**（CSV/TXT），不是 Seurat 对象；大多是 bulk 组学/临床（火山图、生存曲线、森林图、热图、GSEA、免疫浸润、circos 等），少量单细胞。
- 许可证 **CC BY-NC-SA 4.0**（署名-非商业-相同方式共享）；部分模块输入超过 GitHub 限制，只在百度网盘。
- ★ 为我的建议。每题有"补充"行。

## 一、范围与优先级

### 1. 入库范围
- [ ] A. 全部模块（数百个；工作量很大，按批次进行，估计以周计）
- [ ] B. 先做一个代表批次（如 30–50 个最常用图型：火山、热图、生存/KM、森林、GSEA、箱线/小提琴、相关性、circos…），之后按需扩展 ★
- [ ] C. 只做与现有课题方向相关的（单细胞、眼科/青光眼、机器学习可解释性等）
- [ ] D. 由我列出模块编号清单

- [ ] A. 先把 SCP 全部做完（含正式合入），再开 FigureYa ★
- [ ] B. 两者并行（FigureYa 先做盘点与设计，不动正式库）
- [ ] C. 暂停 SCP，优先 FigureYa

## 二、模板定义（FigureYa 输入本来就是表）

### 3. FigureYa 绘图模板的形态
- [ ] A. 表驱动 CSV 模板（与现有 17 个 SCP 模板同一机制：接口页定义列、换数据直接出图、回放验收）★
- [ ] B. 方法页下的"可视化实现"（与 SCP Seurat 版同一机制：复制函数代码，按收据验证）
- [ ] C. 两者：纯绘图部分做 CSV 模板；含分析计算的部分（如差异分析、生存模型、GSEA 计算）做方法实现
- 补充：

### 4. 一个 Rmd 里有多张图/多种变体（如 FigureYa59 同时有 classic 与 advanced 两张火山图）
- [ ] A. 每张结构不同的图各一个模板 ★
- [ ] B. 一个模块一个模板，变体作为参数
- 补充：

### 5. 分析与绘图混写的 Rmd（先算再画）
- [ ] A. 拆开：分析步骤入方法家族（汇入已有规范家族，如差异表达、生存分析），绘图步骤入模板，页面写明链路 ★
- [ ] B. 整个 Rmd 作为一个"流程"保存，不拆
- [ ] C. 只取绘图部分，分析部分不入库
- 补充：

### 6. 验收标准
- [ ] A. 与 FigureYa 原始 Rmd 在其示例输入上的输出逐像素一致（需在本机先跑通原 Rmd；缺包的模块不安装，记 not_run）★
- [ ] B. 与仓库里已有的输出 PDF 对照（不重跑原 Rmd；PDF 因字体/版本可能有差异，比较结构）
- [ ] C. 能出图、人工看过结构正确即可
- 补充：
