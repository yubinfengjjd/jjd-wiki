# SHAP 单panel图样归类纠正

2026-10-21，依据作者纠正：“SHAP三个图也是单图模板，为什么不归入？”

上一轮把“单panel图样”限定成独立来源页，是错误解释。此解释已由当前Wiki AGENTS与两技能规则取代，不能再以“只有2条来源记录”为理由把已有SHAP单panel排除出图样栏。

## 正确行为

- 单panel图样按逻辑图形样式浏览，包含SHAP条形（含inset）、蜂群、环形三个现有单panel模板，以及密度散点与边缘分布、箱线散点与均值，共5种。
- 可调用模板按函数入口浏览，目前5个。同一条记录可以在两个入口出现，两栏不互斥。
- 有明示来源覆盖时只显示一个图样代表；只有历史模板而没有独立单panel来源页时，直接展示并链接既有模板，不要求重新入库。
- 整图本身继续归档隐藏，保留来源链接和已有能力限制。没有新增来源、模板、方法、待办或签核。
- 图样数不是强制等于函数数：图样对应的函数若被归档，来源图样仍可见；数量应反映真实内容。

实现：`figureModels.galleryEntries` 统一构成两个可重叠视图，按明示来源/模板覆盖去重；图库卡片按所在入口标为图样或函数，模板详情说明同时属于两种入口。删除了把模板互斥归入模板栏的旧筛选。
