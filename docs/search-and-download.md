# 检索、证据与下载

默认 knowledge 范围查询完整知识章节；source 范围只搜索本机已经下载的代码和来源说明，排除数据表、日志与二进制。不读取作者 user 备注或自动生成 facts 作为全文语料。

查询用 BM25、中英文术语及中文片段；命中片段不能代替完整方法前提。索引是可重建的本机派生文件，不保存长期可执行授权。静态索引的状态带导出时间，使用前需在本地核对。

## 三类状态

| 显示 | 含义 |
|---|---|
| available | 当前检出的预期资产存在；仍需看对应验证范围 |
| not_downloaded | Git 稀疏检出有意省略，不等于科学或执行失败 |
| missing | 当前预期文件确实不在工作区，需核对；不覆盖本地文件 |

## 显式操作

```text
rwiki assets fetch <id>
rwiki use <id> --project <课题目录>
rwiki checkout --profile full
```

assets fetch 和明确的 use 可以获取所需条目；网页点击“下载资料”才发起 POST 获取。打开页面、GET 查询和静态检索不触发 Git 资产下载。失败保留已有下载，可检查网络后重试；不会安装分析依赖。

light 可查找、阅读、获取与复制，不能正式入库、确认、改状态或保存 Wiki。full 切换前必须先保存检出中的修改；不会覆盖尚未提交的工作。资产完整、当前实现已验证与适用某个科研问题是不同事实。
