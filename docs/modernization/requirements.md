# 检索与双仓库规范化需求基线

状态：实施中。需求来源：作者在 2026-11-13 的逐轮访谈及其后明确要求实施的计划。

## 已确认决定

| 编号 | 决定 |
|---|---|
| Q001–Q003 | 自己使用优先兼顾公开；保留双仓库；检索知识供现有 agent 使用，不新增网页问答 |
| Q004–Q006 | 英文工程目录和中文内容；兼容常用命令的自动迁移；轻量与完整两种获取方式 |
| Q007–Q009 | 正文知识优先、源码按需；首版离线且无新增模型；全局搜索与分类浏览并存 |
| Q010–Q011 | 历史档案归组且原名保留；轻量版查找复用，完整检出正式维护 |

## 必须保持

- 原始来源、许可证、作者 user 区块、固定知识 ID 与科学统计逻辑。
- 页面确认、代码验证、独立性证据和真实课题适用性分别解释。
- 查询不安装包、不运行科研代码、不隐式下载缺失 Git 资产。
- Git 默认保留全部知识；派生索引、环境与临时测试材料不属于知识原件。
- 不读取、调用或引用 paper-harness。

## 验收

40 个预先标注的查询场景：15 方法、10 模板、10 理论/接口、5 限制条件；相关页 Top5 比例至少 90%。固定回归包括差异表达两种问法与细胞注释日常问法 Top3、coexpression 不再扩展为 PR。

同时验证正文独有术语、跨入口一致、证据变动失效、轻量缺失分类、显式下载与失败保留、全量切换、迁移回退、新旧及同级布局、作者区块和来源字节保持，以及实际浏览器搜索、详情、代码与下载。

## 不纳入本轮

语义模型、付费接口、数据库、网页聊天、原算法修补、已有科研失败分支重跑或无证据消除警告。
