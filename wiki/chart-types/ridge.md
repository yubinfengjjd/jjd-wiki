# ridge

## 回答什么问题

ridge（山脊线/密度脊）回答的是：一个连续变量在多个有序分组中的分布形状，包括峰值位置、峰的个数、离散程度和组间重叠。每组一条密度曲线，沿 y 轴堆叠，适合同时比较多个组的分布而不是只比较均值。它不直接给出显著性，也不适合观测很少的组。

## 什么时候选它

连续变量（表达、得分、时间、浓度）在每个组内有足够观测（足以估计密度），组数中等且组顺序有含义（如细胞类型、发育阶段、处理剂量）时选它。组顺序应显式给出，并让密度脊沿一个方向排列；需要看分布形状、双峰或长尾时，ridge 比箱线/小提琴更直观。若每组样本很少或只需要中位数/IQR，改用箱线图或逐点展示。

## 什么时候不要用

不要用 ridge 展示分类计数、比例或只有几个观测的组；核密度在 n 很小时会造出虚假的峰。不要用它代替统计检验或把重叠程度读成显著性；不要用它展示两个连续变量的联合关系（改用密度散点/hexbin）；组数太多时高度会压缩标签和曲线，应减少组或改用分面。不同组样本量差异很大时，密度高度按组归一化，不能按高度比较组的总量。

## 与相近图型怎么区分

与 violin 相比，violin 每个类别一个对称密度、通常沿 x 轴排列，适合少量类别；ridge 把多个密度沿 y 轴堆叠，更适合有序组和分布形状比较。与 boxplot 相比，箱线只给中位数/IQR/离群，ridge 保留峰的个数和尾部形状，但不直接给四分位。与 histogram 相比，histogram 是一个变量的分箱计数，ridge 是分组后的平滑密度；与 density-scatter 相比，后者是二维散点/密度，不表达分组分布。与 beeswarm 相比，后者显示每个观测点，ridge 是平滑摘要，小样本时应优先逐点。

## 常见误用

最常见的是带宽/平滑参数未说明：过平滑会抹掉双峰，过平滑不足会把噪声当峰；图注应写明密度估计方法与带宽（若可调）。第二类是把不同 n 的组按曲线高度比较总量：ridge 通常按组归一化面积，高度不是组大小。组顺序若按数值排序而非设计顺序，会暗示不存在的趋势；对数尺度、截断的 x 轴或把密度面积裁到 0 也会改变形状。观测很少的组不适合密度；应标注每组 n，必要时改用箱线/逐点。最后，ridge 不替代统计检验，重叠大不等于无差异。
